# Grocery Shopping List

A simple single-page grocery shopping list application built with HTML, CSS, and JavaScript.

## Features

- Add grocery items
- Display all grocery items
- Mark items as bought
- Undo bought status
- Remove items
- Live item counter
- Empty-list message
- Responsive design

The application uses a state-then-render approach.
